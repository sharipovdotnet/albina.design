# albina.design

Одностраничный сайт дизайнера интерьера: галерея проектов в виде непрерывной сетки
прямоугольников на белом фоне.

## Стек

HTML, CSS, TypeScript. Сборка — Vite, без фреймворков, CSS-библиотек и UI-китов.
Шрифт Golos Text самохостится через Fontsource, внешних запросов за шрифтом нет.

## Команды

```powershell
npm install
npm run dev        # dev-сервер с hot-reload
npm run build      # tsc --noEmit + сборка в dist/
npm run preview    # локальный просмотр сборки
npm run typecheck  # только проверка типов
```

## Структура

```
index.html                 разметка страницы
src/styles/main.css        стили: токены, layout, компоненты
src/ts/main.ts             точка входа
src/ts/gallery.ts          отрисовка карточек галереи
src/ts/data/projects.ts    данные проектов
public/images/projects/    обложки проектов, см. README внутри
```

## Как устроена сетка

Ячейки разделены отступом 5 px по горизонтали и вертикали, поэтому общую линию они не делят:
рамку в 1 px несёт каждая ячейка, а контейнер своих линий не рисует. Ячейки вертикальные
(3:4). Колонок: одна
до 640 px, две до 1024 px, три до 1280 px, четыре дальше. Боковые отступы `main` — 300 px,
пока экран не уже ~1364 px, дальше они уменьшаются пропорционально.

Фотографии по умолчанию монохромные. Цвет возвращается при наведении мыши, а на тач-устройстве
и с клавиатуры — по тапу или Enter/Space: обработчик в `src/ts/gallery.ts` вешает на ячейку
класс `is-revealed`, повторный тап возвращает ч/б.

## Что осталось заглушками

- Контакты в `<footer>` — в `index.html` стоит TODO.
- Обложки: у всех проектов `cover: null`, поэтому рисуется пустая рамка. Файлы кладутся
  в `public/images/projects/<slug>/cover.jpg`, путь прописывается в `src/ts/data/projects.ts`.
- Названия проектов на странице не показываются: подписи из ячеек убраны, поле `title`
  в данных осталось только для `alt` у фотографии. Сами названия выдуманы, их двенадцать;
  количество теперь произвольное — ячейки больше не связаны общей линией, поэтому неполный
  последний ряд ничего не ломает.
- Favicon не добавлен.
