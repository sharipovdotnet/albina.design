# Фотографии проектов

Обложки лежат здесь: `public/images/projects/<slug>/cover.jpg`. Содержимое `public/` раздаётся
как есть, поэтому в данных проекта путь указывается от корня сайта —
`/images/projects/<slug>/cover.jpg`.

`<slug>` — поле `slug` из `src/ts/data/projects.ts`.

## Требования к обложке

- пропорции 3:4 (например, 1200×1600) — ячейки вертикальные, под них задан `aspect-ratio`;
- ширина от 1200 px, вес до 300 КБ, форматы JPEG или WebP;
- без водяных знаков, подписей и коллажей из нескольких кадров.

## Как добавить проект

1. Положить файл в `public/images/projects/<slug>/cover.jpg`.
2. В `src/ts/data/projects.ts` прописать `cover: '/images/projects/<slug>/cover.jpg'`.
3. При необходимости уточнить `alt`: сейчас он собирается из названия проекта
   («Интерьер: …»), а для портфолио лучше описывать конкретный кадр.
