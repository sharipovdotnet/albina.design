# Фотографии проектов

Обложки и серии лежат здесь: `public/images/projects/<slug>/`. Содержимое `public/` раздаётся
как есть, поэтому в данных проекта путь указывается от корня сайта —
`/images/projects/<slug>/cover.jpg`.

`<slug>` — поле `slug` из `src/ts/data/projects.ts`.

## Что должно лежать в папке проекта

- `cover.jpg` — обложка ячейки сетки: ровно 3:4 (1200×1600), до 300 КБ;
- `01.jpg`, `02.jpg`, … — кадры серии для окна галереи: длинная сторона до 1800 px, до 500 КБ.
  Первым идёт кадр обложки, дальше — порядок автора.

Формат — JPEG. Без водяных знаков, подписей, QR-кодов и коллажей из нескольких кадров.

## Как добавить проект

Файлы готовит `tools/prepare-photos.ps1`: он сам режет обложку под 3:4, уменьшает кадры
до нужной длинной стороны и подбирает качество, чтобы уложиться в вес.

```powershell
# папка с исходниками -> public/images/projects/zhk-uno
powershell -NoProfile -ExecutionPolicy Bypass -File tools/prepare-photos.ps1 `
  -Source "D:\Проекты\ЖК UNO" -Slug zhk-uno -Cover "2final (1).jpg"
```

`-Cover` — имя файла-обложки в папке с исходниками; без него берётся первый вертикальный
кадр. Остальные параметры (`-CoverWidth`, `-SeriesLongSide`, `-CoverMaxKB`, `-SeriesMaxKB`)
меняются редко. Скрипт печатает готовый блок `photos` — его остаётся вставить в
`src/ts/data/projects.ts` вместе с `slug`, `title` и `cover`.

Порядок кадров серии — «естественный»: по первому числу в имени файла, затем по имени,
поэтому авторская нумерация (`1final`, `2final`, `10final`) сохраняется. Обложечный кадр
встаёт первым.

`alt` собирается сам из названия проекта («Интерьер: …»). Своих подписей у кадров нет:
если появятся, их придётся добавить в данные и в `src/ts/lightbox.ts`.
